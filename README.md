#  TuneWave – Music Player App

##  About the Project
TuneWave is an Android music player application developed using Kotlin. The app is designed to provide users with a simple and user-friendly music listening experience.

##  Features
- Clean and user-friendly interface
- Music playback functionality
- Easy navigation
- Android application development using Kotlin

##  Tech Stack
- **Language:** Kotlin
- **Platform:** Android
- **Build Tool:** Gradle

##  Objective
The objective of TuneWave is to build an Android application that provides a smooth and convenient music listening experience while improving my skills in mobile app development.
